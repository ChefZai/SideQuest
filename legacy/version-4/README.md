# SideQuest Version 4 archive

Version 4 was the final Sunlit Scrapbook web baseline before Living Quests. It includes the Quest Foundation, Journey System, Product Focus Reset, reliable Quick Capture, templates, Inspiration, Help, responsive corrections, and the final visual/UX audit.

- Exact commit: `eeb8dfd`
- Annotated tag: `v4-final`
- Recovery branch: `archive/version-4-final`
- Production project at the time of archival: `sidequest-2e798`

This folder is documentation only and is not part of the active build. The permanent source snapshot lives in Git so the active TypeScript and CSS are not duplicated or accidentally bundled.

To restore Version 4 safely, create a new branch from `v4-final` (for example `git switch -c restore/version-4 v4-final`). Do not overwrite Version 5 user data or shared history. Version 5 is the active implementation.
