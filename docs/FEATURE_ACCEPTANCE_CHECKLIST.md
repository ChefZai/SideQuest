# SideQuest Feature Acceptance Checklist

Before building or retaining a feature, answer:

- Does it make inspiration easier to capture?
- Does it make sharing safer or easier?
- Does it reveal genuine shared excitement?
- Does it help make a Quest real?
- Does it preserve a meaningful memory?

At least one answer must be yes. Then verify:

- It reduces friction or creates clear emotional value.
- It does not create pressure, guilt, addictive behavior, or administrative work.
- It does not make SideQuest resemble productivity software or a social network.
- Planning appears only when useful.
- The simplest path remains obvious and accessible.
- Removing it would weaken the core loop.
