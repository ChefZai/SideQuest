# SideQuest Product Metrics

## North Star

**Meaningful Quests made real per active Space.**

## Core-loop events

- First Quest Saved
- Quest Shared
- Invitation Accepted
- Reaction Added
- Time to First Reaction
- Shared Quest Received Feedback
- Mutual Interest Detected
- Quest Entered Planning
- Quest Completed
- Completion Reflection Added
- Memory Viewed
- Quick Capture Started
- Quick Capture Completed
- Capture Source Type

These events must never include private Quest text, comments, invite codes, email addresses, image URLs, or precise locations. They are product-health signals, not a user-facing productivity score.
